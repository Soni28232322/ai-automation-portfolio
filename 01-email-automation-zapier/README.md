# 📧 Email Automation using Zapier

## 🎯 Goal
Automate email responses when a user submits a form.

---

## ⚙️ Tools Used
- Zapier
- Google Forms
- Gmail
- OpenAI (optional for AI replies)

---

## 🔄 Workflow

1. User fills out Google Form
2. Zapier detects new submission
3. Data is processed
4. Email is automatically sent to the user

---

## 🧠 What I Learned
- How triggers and actions work in Zapier
- Basic automation logic
- Connecting apps without coding
